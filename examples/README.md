# Examples

This directory contains usage examples demonstrating core-libraries functionality.

## Purpose

Examples should demonstrate:
- Common use cases
- Integration patterns
- Best practices
- How to use the public API

## Structure

- One example per feature or use case
- Include build instructions if needed
- Add explanatory comments
- Keep examples runnable and tested

## Guidelines

- Keep examples simple and focused
- Include enough context to understand the pattern
- Use consistent coding style with the main codebase
